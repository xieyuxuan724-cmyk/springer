# BENI 避障 V2：边界感知与探索约束

## 本次调整

保留原来的有限宽度场地、3 m 目标方向进度和成功/失败判定。没有把放宽边界或删除停车验收当作成功率提升。

| 项目 | V1 | V2 |
|---|---|---|
| 单帧/堆叠观测 | 45 / 135 | 49 / 147 |
| 边界信息 | 无 | 左右安全界距离、后方界距离、距终点的剩余进度 |
| 前进奖励系数 | 2 | 0.5 |
| 成功奖励 | +10 | +20 |
| 越界惩罚 | −10 | −20 |
| 接近边界 | 无 | 剩余安全距离低于 .35 m 时二次惩罚，最大每步 −.2 |
| PPO 熵系数 | .01 | .001（固定） |
| 初始动作标准差 | .6 | .4 |
| 实际高斯采样标准差范围 | 默认极宽范围 | [.1,.6]，使用 RSL 原生 std_range |
| 随机导航训练零命令占比 | 10% | 0%；保留独立零命令诊断 |

其它奖励、底层权重、非负前进命令范围、控制周期和物理后端不变。所有修改通过配置中的 `version=2` 标识；边界缓冲距离和权重也保存在配置里。

新观测为：原有 45 维之后追加 `(L-y)/(2L)`、`(L+y)/(2L)`、`(x+.4)/(3+.4)`、`(3-x)/3`，其中 L=1.5−.19=1.31 m，x/y 位于回合目标方向坐标系。后两项使用实际 target_distance 参数而不是固定 3。策略现在能区分靠近左界、右界、后界和终点的状态；不强制回到原行进直线。

边界惩罚为 `-.2 * clip((.35-d)/.35,0,1)^2`，d 取左右安全界及后界的最小距离，仅非零速度、稳定期之后生效。终点不施加边界惩罚。原生播放器画出红色左右/后方任务界限和绿色终点线；它们是虚拟任务边界，不是实体墙。

这些距离在仿真中由机器人位置计算；如果以后部署实机，需要定位/里程计提供相同坐标定义，不能假设仅靠前向测距就知道边界。

## 停车问题的处理范围

本次没有修复冻结底层的停车漂移。V2 导航训练只采样 .1–.5 m/s，避免在上层缺乏反向制动能力时混入大量停车失败回合。独立零速度验证仍默认执行 3 场，原阈值不变；手动播放仍可设零速度，奖励也保留。

因此，导航成功率提升不能代表完整的 0–.5 m/s 任务通过。零命令能力仍需独立进行底层策略/部署参数诊断，再决定是否修正或更换底层；本次未擅自更换底层或允许倒车。

## 版本兼容

- 旧检查点缺少 version 时按 V1 解释，仍用 135 维观测及原奖励，可继续播放和评估。
- 新检查点为 V2，使用 147 维观测，加载时核对模型输入宽度和配置。
- 训练入口禁止通过 `--resume` 将 V1 接入 V2；V2 从头训练。旧优化器/归一化不搬到新版。
- V2 检查点可以正常 `--resume`，继续使用保存的算法配置。
- 原有历史训练目录及检查点保留，不覆盖。

## 下一轮建议：先短训对照

本次只执行 CPU 小规模验证，没有自动启动下面的 GPU 训练。确认 GPU 可用后，在仓库根目录运行：

```bash
uv run python scripts/train_avoidance.py --backend warp --num-envs 32 \
  --iterations 300 --steps 64 --minutes 30 --seed 42 \
  --validation-interval 50 --validation-episodes 12 \
  --validation-zero-episodes 3
```

先比较第 50/100/150/200/250 轮的同种子验证，关注越界率是否下降、导航成功率是否超过旧版波动区间。不要仅凭总奖励判断进步：奖励尺度已改变，V1/V2 总回报不可直接比较。若边界失败仍高，应看轨迹和动作饱和率，再决定是否扩大训练。

12 场只用于趋势；候选检查点再与旧版 model_500.pt 在同一较大验证集比较，例如：

```bash
uv run python scripts/evaluate_avoidance.py --backend native --num-envs 4 \
  --policy logs/rsl_rl/beni_avoidance/<v2-run>/model_250.pt \
  --episodes 100 --seed-base 2000000 \
  --output logs/avoidance_validation/v2_250_validation.json
```

旧版使用同样参数，替换 policy 和 output 即可。此处仍是验证集；最终测试种子 3000000 段继续留给最终验收。正式对比不要把随机规则基线当作训练策略。

## TensorBoard 新指标

- `RewardStep/boundary`、`RewardEpisode/boundary`：边界惩罚贡献。
- `Exploration/saturation_vx`、`Exploration/saturation_yaw`：经过 tanh、尚未命令限速前，动作绝对值大于 .95 的比例。
- `Policy/mean_std`：实际分布标准差，V2 应不超过 .6；均值过大仍可能使 tanh 饱和，故还需要看饱和率。
- 保留 `Failure/bounds`、独立导航/停车验证、分速度/课程指标。随机训练不再包含零速，故训练 `Stop/*` 通常没有点，独立 `Validation/native/zero/*` 仍会出现。
